# AlligatorT Homebrew Tap

Homebrew formulae for [AlligatorT](https://github.com/AlligatorT) projects.

## SkillsPub

[SkillsPub](https://github.com/AlligatorT/SkillsPub) — multi-agent skills on/off manager (disk is the source of truth).

Install:

```sh
brew install AlligatorT/tap/skillspub
```

Upgrade:

```sh
brew upgrade AlligatorT/tap/skillspub
```

Requires Node.js 22.20+ (satisfied by Homebrew's `node` dependency). The formula installs the exact, SHA-256-verified npm release tarball published for each version — no moving branches.

Formula bumps are published manually with each SkillsPub release; automatic bumps are deferred until the release process is proven.

## Other commands

```sh
brew tap AlligatorT/tap          # register the tap without installing
brew uninstall skillspub         # remove
```
